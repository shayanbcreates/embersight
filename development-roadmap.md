# EmberSight development roadmap

**Development Status: In Progress**

This is a phased plan for proposed development.

### Phase 1: Foundation

Choose a small study region and assemble licensed public weather, vegetation, terrain, and historical data.

### Phase 2: Core system

Build reproducible geospatial processing and a transparent baseline risk map with provenance.

### Phase 3: Evaluation

Add scenario comparison and uncertainty displays; backtest against historical periods.

### Phase 4: Hardening

Improve refresh automation, performance, cost limits, and documentation of model limits.
